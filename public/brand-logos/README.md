# Product-share brand logo assets
These local SVG assets reproduce recognizable company brand marks rather than generic UI icons. They were added for product-sharing links; they **do not imply endorsement or partnership** with the companies.

| Local SVG | Vector asset source | Brand usage reference |
|---|---|---|
| facebook.svg | https://github.com/simple-icons/simple-icons/blob/develop/icons/facebook.svg | https://www.meta.com/brand/resources/facebook/logo/ |
| x.svg | https://github.com/simple-icons/simple-icons/blob/develop/icons/x.svg | https://about.x.com/en/who-we-are/brand-toolkit |
| linkedin.svg | https://github.com/FortAwesome/Font-Awesome/blob/6.x/svgs/brands/linkedin.svg | https://brand.linkedin.com/in-logo |
| whatsapp.svg | https://github.com/simple-icons/simple-icons/blob/develop/icons/whatsapp.svg | https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/ |
| telegram.svg | https://github.com/simple-icons/simple-icons/blob/develop/icons/telegram.svg | https://telegram.org/press |
| pinterest.svg | https://github.com/simple-icons/simple-icons/blob/develop/icons/pinterest.svg | https://business.pinterest.com/brand-guidelines/ |

Source distinction: these SVG glyph files come from the named icon repositories, **not directly from brand owner asset ZIPs**. Brand documentation was checked to identify official usage resources. Follow the respective brand guidelines and licensing requirements if expanding use beyond product share links.

The SVGs scale to any resolution (including 4K) without pixelation. Their current fills use known brand colors. Email and Copy Link are utility actions and therefore use mail/link icons instead of unrelated company logos.
